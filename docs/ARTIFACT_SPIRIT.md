# 器灵

器灵入口是 /artifact-spirit。功能卡先展示一句简介，展开「详情」可看实际能力、关联入口和已上线变化。维护 app/modules/artifact_spirit/catalog.py 里的条目，页面和器灵问答会同时使用更新后的清单。上线新入口时同步记录功能说明和具体变化。

登录后打开功能区会计数。同账号、同功能区在上次有效打开后十分钟内不重复计数。列表显示近 30 天和累计次数，从 0036 上线起统计。闪光的回忆等模块下的多个子页合计到一级功能区。

低使用候选按近 30 天次数与其他可比较功能区做对比，一次最多三个。没有可比较的使用记录时不会发起 AI 请求。账户、设置等管理入口仍计数，仅从建议候选中排除。点击「生成使用提醒」才会把候选的计数和功能说明发给模型。顶部显示概括，右侧显示具体建议和入口。

「向器灵提问」使用同一份已上线功能清单。每次带当前问题与最近四轮，会话正文保留在页面内存，刷新、离开或点击清空后消失。项目数据库沿用灵石区调用记录，只留请求状态、用量等元数据，不保存问答正文。

0036 新增 feature_visits。完整 PostgreSQL 备份会包含该表，页面内的导出不作为完整备份。功能使用次数按用户归属隔离。

验证包括导航与清单一致性、隔离 PostgreSQL 上的计数与账号隔离、桌面与 390px 浏览器布局、两轮问答与刷新清空、当前真实模型的提醒与来源入口。默认测试 198 通过，器灵专项 3 通过。生产数据库版本为 0036，重启后器灵页面和健康检查均返回 200。
