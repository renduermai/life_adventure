# 藏经阁：链接书架

## 使用

登录后，从左侧「藏经阁」查看本人全部有效链接；也可在主线或副本的列表、详情中点击「拆解」旁的「书架」。后者会自动筛选当前任务，并在新增表单中预选它。主线书架只包含直接关联该主线的资源，不包含子副本的资源。

填写描述、完整HTTP/HTTPS网址，选择一个主线或副本，点击「发送」。保存后输入框清空，任务选择保留；失败时保留输入。每条链接的所属任务下拉框修改后立即保存；改挂后若不符合当前筛选，会从列表移除。点击删除前需确认，只删除链接，不删除任务。普通打开网址会打开新标签页，不增加次数。

链接左侧「复制」成功后，显示的已复制次数增加1，列表按次数降序排列；次数相同按创建时间从新到旧排列。复制使用浏览器Clipboard API，本地127.0.0.1/localhost或HTTPS可用；拒绝剪贴板权限时显示错误，不增加次数。复制成功但计数响应未确认时，按钮显示「重试计数」，使用原操作编号，不再次复制、不重复计数。先确认计数结果再关闭页面：待确认操作编号仅保留在当前页面，刷新或关闭后不能继续重试该编号；已经保存的次数与凭据始终在数据库。服务端只能验证计数请求归属和幂等，无法独立验证系统剪贴板；次数表示用户通过本页面成功复制并确认入库的次数。

筛选任务和新增任务下拉框读取真实数据库标题，任务改名后刷新即可看到新标题。关联任务删除/不可用时默认列表隐藏其资源；链接数据仍保留，本人详情API可读取target_available=false，可改挂或删除。原任务恢复后资源重新出现。无权限或无效书架入口明确报错，不回退展示其他任务。

## 数据与接口

数据库版本 `0021_library_copies`；`library_links`保存原始描述、URL、唯一任务关联、次数、版本、软删除和幂等创建信息；`library_copy_receipts`保存每次复制的用户/操作UUID及链接。复合外键约束同一用户，CHECK保证主线/副本恰好一个。主副本只读查询，不改变完成状态、五色、经验金币，不导入或调用AI。

- GET `/api/library/targets`：本人可用主副本。
- GET `/api/library/links`：全部或main_quest_id/task_id筛选，offset分页，每页20条。
- POST `/api/library/links`：request_id、description、url和main_quest_id或task_id。
- GET/PATCH/DELETE `/api/library/links/{id}`：详情、改关联、软删除；后两者携带expected_version。
- POST `/api/library/links/{id}/copies`：剪贴板成功后提交request_id；同一用户同一操作编号只计一次。

新标签普通GET、列表加载、鼠标悬停、编辑关联、刷新均不计数。计数使用SQL原子+1，凭据同事务写入；并发不会覆盖旧数值。URL最多2048字符，描述最多500字符；拒绝空白描述、非HTTP/HTTPS、非完整URL、控制字符/空白/反斜杠或嵌入账号密码。后端不抓取网址。

## 备份与恢复

当前应用「数据与恢复」固定名单导出**不包含library_links、library_copy_receipts**，不能作为藏经阁备份。应执行完整PostgreSQL备份，包含这两张表、users、main_quests、tasks及迁移版本；如果仅备份模块表，须保证恢复库中引用用户与任务的UUID及归属一致。链接可能含私人网址或查询参数，备份文件应限制访问、妥善加密。恢复先在独立库验证表行数、关联、复制次数及唯一操作凭据，再切换连接。不能只恢复计数而丢掉对应操作凭据，否则失去重复请求保护。真实库不要执行降级删表；回退应用需要兼容当前迁移版本检查。本轮没有创建完整生产备份，也没有执行全库恢复演练。

## 网页验收

1. 从主线列表、主线详情、副本列表、副本详情分别点击书架，确认筛选和新增选择正确，进入书架不创建链接。
2. 各保存一个主线资源和副本资源，确认主线书架不混入子副本资源；左侧藏经阁显示全部。
3. 左侧复制三次，粘贴核对URL、次数为3；直接打开不加次数，刷新和重启仍为3。
4. 修改关联后当前筛选中移除，切换新任务可找到；删除链接后原任务仍在。
5. 另一账号不应读取或计数本人链接。检查390px/手机布局。

运行：`.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log`，打开 `http://127.0.0.1:8000/library`。
