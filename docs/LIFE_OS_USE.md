# 人生运行系统使用说明

登录后打开 /life-os。顶部“保存并分析”先保存原文，勾选本轮外发授权后才发送近期必要对话。可继续围绕同一件事讨论或反馈实际做过的行动；事件归属不确定时先确认，勿把每条消息都当成新事件。模型估计的能量、带宽、生活秩序可手动校准。

问题说明书按确认事件次数排序。点击查看来源、实际反馈与建议，管理误分类、合并、归属修正和手动机制；手动填写内容受保护。杂念只在明确选中时作为背景，登记历史事件也要确认来源去重。

点击双五层中的层次记录个人经验。运行模式区区分实际模式与AI建议；手动选择一直保持，直到恢复跟随AI。没有哪种模式代表个人价值。

创建场景，填写每日/每周原始模板，把真实义务标为固定。日均时间与跨日锚点按账号时区显示；日程授权勾选后，可生成每日/每周建议，并在必要状态变化时自动更新。原始模板不被AI修改，历史结果独立保存。核心/日程/吸引子的模型调用在本页串行执行；其他页面或设备同时调用仍可能受到Gateway限流，应保留原文后手动重试。

在生活保障区展开编辑，可采用默认示例或自行填写事项及恢复阶段。每日勾选只表示真实做过的事；历史日期可查看和补充反馈，跨日后不背昨天的进度。成功节点不是心理恢复的诊断。蓝色模式下现有分析可以参考自己的恢复协议，不自动升级阶段。

环境吸引子默认近15天，可选7/30天或自定义日期。明确勾选本模块外发授权后点击分析；后续有效事件变化可增量更新。杂念需要在顶部另行选中。每轮最多12个已确认、有来源事件，日期范围最多91天；超限缩小范围，不会悄悄遗漏事件。每事件最多3个来源，AI只接收每来源前600字，点散点仍可读完整原文。单次观察和多次关联分开标记；位置和距离仅为假设示意。

出现超时、截断或格式错误时，原文和上次成功分析保留。日程与地图错误各自显示，不代表核心对话丢失。若来源已删除、授权取消或版本过期，先刷新并重新选择范围，不继续沿用失效引用。

新电脑可按 docs/RECOVERY.md 恢复代码/环境及数据库，保留原 .env 和AI_ENCRYPTION_KEYS。页面JSON/CSV导出尚不包含所有模块，不能当全库备份。数据库全量备份必须包含所有life_os_*表和依赖，图片对象另行备份；本机加密检查点不等于异地备份。
