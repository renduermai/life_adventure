# 精神导师人物分析：截断最小修复（2026-11-22）

## 原因与证据

已定位的真实故障为供应商返回 `finish_reason=length`，不是 `.content` 提取失败。原请求输出预算为4096，未显式设置思考模式；原失败日志没有用量，不能重建当次完整响应或精确分配推理/最终答案Token。

百炼官方文档说明当前 `deepseek-v4.1-flash` 默认启用思考，并支持REST顶层 `enable_thinking=false`。真实合成对照使用原4096预算、历史Schema和代表性简短提示，返回stop，总输出1593 Token，其中推理1006 Token、推理文本4202字符；此次对照没有截断，不能冒充复现原用户失败。它证明当前接口的默认思考确实占用输出预算。官方依据：[深度思考](https://help.aliyun.com/zh/model-studio/deep-thinking)、[DeepSeek API](https://help.aliyun.com/en/model-studio/deepseek-api)。

## 最小改动

- 人物分析Prompt/新生成Schema限制标签20字、总结150字以内（目标100–150字）、正面影响3条、负面说明最多3点、主副本关联合计3条、杂念关联3条、联系建议3条。短证据40字以内，继续逐字匹配授权原文。联系理由仍由原Python评分函数组合，不新增重复输出字段。
- 历史结果仍用旧PersonOutput读取；新生成使用其紧凑子类，字段名称和结构不变。升级Prompt版本，使旧缓存不会阻止新配置生效；旧结果保留，可显示过期提示。
- 仅person_analysis预算8192；仅当前百炼maas域名上的deepseek-v4.1-flash人物分析显式关闭思考。其他模块预算、配置和思考行为不变。
- 仅人物分析增加数字/枚举诊断：预算、结束原因、Token用量、最终内容与推理文本长度、显式思考设置。供应商没返回推理Token时保持缺失，不推断为0。截断用量保存到现有ai_call_logs.usage，不记录私文或密钥。
- 即使JSON完整，只要finish_reason=length仍拒绝保存。原授权来源、证据校验、Python联系评分/联系热度、失败保留旧成功分析均不变。

涉及业务文件：people/analysis.py、people/analysis_schemas.py、ai_gateway/adapter.py、ai_gateway/service.py。新增两份针对性测试；没有安装依赖、数据库迁移或修改.env。
