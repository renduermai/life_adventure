# 灵根 · 第 4 步

从侧栏进入「灵根」，粘贴 AI 新发现、想法或真实经历，点击「AI 灵力探查」。每次上限 10,000 字符。原文先按当前账号保存，再将该段文字和最多 60 个近期已有条目的分类、名称和编号发送给灵石区。其他功能区的私人原文不读入这次分析。

天赋显示出现次数和最近一次有依据的强度，点击名称回看历史，点击强度看本次判断依据。外部信号标签表示原文记录了外部反馈或表现，由模型提取，不代表外部独立核实。信号可显示同轮已确认或以前记录的关联天赋，点击「详情」可回看历史与原文片段。

出现次数按不同原文计算。同一段只改变首尾空白或换行格式时视为相同，并保留第一次提交的原文。同一原文中同一条目最多计一次。明确同义且模型引用了合法旧条目时合并，可能同义时进入待确认。可以合并到建议的旧条目或保留为独立条目。分析通过后才发布发现，失败时可用已保存的原文重试。

## 图腾、心神修炼和可能抵达的位置

初版图腾按参考图呈现，以认知创造力关联五个基础节点。后续探查可以添加有具体行动或反馈支持的天赋节点。点开有依据的节点可追溯原文。心神修炼对照展示潜在优势和可能的失控情形，后者按假设表述。

发展栏目分职业演化路径与长期验证方向。每条有依据与可验证的小行动，模型识别为同一方向时保留旧版本，新证据成为最新一版。初次没有证据时显示空状态。

旧提交可从「最近提交的原文」打开，再点「补充图腾与发展分析」。这个操作复用原文且不增加天赋或信号出现次数，只补充发展内容。新提交与原有探查一起生成，引用和现有天赋归属经过校验。0038 给灵根原文表新增发展快照字段，完整数据库备份包含这些历史。

探查时按原文切分并编号，由模型在各模块选择依据编号，展示的原文片段由系统直接取回。只要有可核验的结果，就保存并展示对应模块，无法定位依据的单项暂不纳入。若这次没有任何可核验项，原文仍可继续重试。通过「最近提交的原文」可加载更早的记录，在原文详情中确认删除。删除会移除这份原文、其独有证据和发展快照，并重新计算出现次数，其他原文提供的证据继续保留。

原文、天赋、信号、历史证据记录、待确认发现、图腾中的分析节点、修炼对照与发展方向旁提供编辑和删除。原文修改后清除这段原文支撑的旧结果，可重新探查。原文引文和出现次数由系统从来源及记录计算。删除图腾节点会取消展示，仍保留修炼内容。列表与详情里的删除提示会标明影响的是整个条目还是单条历史。

探查和补充分析先让模型按主题组织编号片段，再由系统用原句生成「标题 → 要点」的纯文本，交给模型做分区分析。模型未归类的片段附在整理稿末尾，重复或无效的编号会被忽略。整理服务失败时使用保留所有原文片段的简易分点稿继续分析。保存的原文和引用校验方式不变。
