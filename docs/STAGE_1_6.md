# 阶段 1.6 历练手记

## 授权与范围

用户要求完成 1.6；按模型与迁移、服务与权限、页面、计时联动、验证五部分连续实施。粗略复杂度中高，时间和 Token 受数据库网络及交互验证影响，实际用量无法准确获取。

## 使用与规则

从侧栏进入历练手记，可按日、周、月和分类、副本筛选，查看总时长及按副本汇总；可补录、修改、软删除、恢复记录。专注计时结束自动生成的记录直接显示，不再将计时会话额外累加。

按用户 IANA 时区的记录开始日归属：周一为一周起始；跨午夜记录整条归入开始日。此规则不会根据原始区间拆分，显示在页面；适合查看按记录归属的统计，不代表逐日精确分摊。夏令时不存在的本地时间拒绝；歧义时间使用时区默认第一次出现的时刻。

手工记录支持 0–604800 秒；任务必须属于用户，新增关联需有效。修改自动记录不修改原始计时会话；每次修改、删除、恢复写入前后快照，可通过详情查看。手工补录由提交编号防重，修改使用版本检查防止覆盖。

## 数据与接口

0006_activity 增加记录版本、用户归属唯一约束和 activity_events 审计表；GET /journal、/journal/{id} 提供页面，POST /journal/create、/journal/{id}/edit|delete|restore 校验同源、用户归属并在单一事务中保存。

不包含阶段 1.7 奖励、1.8 首页、1.9 导出和公网部署。
