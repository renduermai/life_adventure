# 阶段 1.9 数据导出、恢复与核心集成测试

用户已授权实施 1.9。本模块提供账号数据 ZIP 导出、统一误删恢复入口、阶段 1 核心流程测试；不涉及阶段 2 AI 或公网部署。

## 导出

登录后在「数据与恢复」点击下载。ZIP 内含 UTF-8 JSON 和各业务表 CSV，按当前用户归属导出，包括软删除数据、目标任务历史、计时区间、行动记录及奖励流水。导出使用数据库一致性快照，不包含密码散列、登录会话、数据库连接或 API 密钥。ZIP 包含个人资料和内容，应自行妥善保存。此版本导出文件不提供自动导入或数据库备份恢复功能。

## 恢复

统一入口展示已删除主线、里程碑、副本和历练记录。主线和里程碑沿用既有操作；副本及历练跳转各自详情恢复，沿用所有权与关联验证。先恢复父主线和父任务，再恢复需要它们的子项。恢复记录不会重发任务奖励。

## 范围与验证

无新数据表或迁移。需隔离 PostgreSQL 上执行真实业务链路与导出、恢复、越权和退出重登检查；需要分别记录是否完成进程重启与浏览器完整端到端验证。
