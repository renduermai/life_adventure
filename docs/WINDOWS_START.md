# Windows 一键启动

双击桌面「人生冒险之旅」快捷方式，或项目根目录 `Start-AdventureCamp.cmd`。地址固定为 http://127.0.0.1:8000 。

`scripts/Start-AdventureCamp.ps1` 使用项目 `.venv\Scripts\python.exe`，工作目录为项目根目录，执行原有 `uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log`。网页模板、JS、CSS由同一个服务提供，不另起前端服务。

启动器以后台隐藏窗口运行服务；健康检查成功后启动器退出，关闭浏览器不会停止服务。重启Windows会停止服务，下次使用时再次双击即可。没有创建计划任务、开机启动项或Windows服务。

## 检查和故障提示

- 重复双击通过当前会话的命名互斥锁串行保护；如果已有启动器在运行，提示等待。
- 8000端口已监听时，核对监听进程或其存活父进程的虚拟环境绝对路径和Uvicorn入口；不属于当前项目或无法确认时直接报错，不结束任何进程。
- 当前项目已运行时复用，不再启动第二个实例，仍须通过 `/health/ready` 才打开浏览器。
- 新启动使用原有配置，不安装依赖、不执行迁移。默认等待约60秒；单次网络超时和系统检查可能使总等待稍长。
- 缺少虚拟环境、入口文件、数据库未配置、迁移版本不符、数据库不可用、端口冲突、进程退出或健康检查超时，均给出提示。失败窗口按Enter关闭。
- 健康检查失败后保留已运行的服务用于诊断。网络恢复后重新双击会复用该服务并再次检查；不会自动结束后台进程。

新启动的服务日志在 `%LOCALAPPDATA%\AdventureCamp\logs\`，每次独立保存 `.stdout.log` 和 `.stderr.log`，错误窗口会显示路径。日志不包含启动器读取的配置值；启动器不读取或打印 `.env`。旧日志没有自动清理，按需要手动整理。复用以前手动启动的服务时，日志仍由原启动方式决定。

命令行诊断可执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-AdventureCamp.ps1 -NoBrowser -NoPause
```

成功退出码0，失败1。`-NoBrowser`用于不打开浏览器；`-NoPause`用于命令行检查时不等待按键。PowerShell执行策略参数仅用于当前启动进程，不修改系统执行策略。

项目整体移动后，`.cmd`和`.ps1`会从自身位置推导项目根目录；Python虚拟环境仍须按迁移说明重新建立。桌面 `.lnk` 保存绝对路径，需要重新创建或修改目标及工作目录。
